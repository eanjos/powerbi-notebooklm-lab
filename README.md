# powerbi-notebooklm-lab
Aplicação do NotebookLM para construção de uma base de conhecimento em Power BI utilizando documentação oficial da Microsoft.

# Power BI Fundamentals com NotebookLM

## Sobre o Projeto

Este repositório apresenta a aplicação prática do Google NotebookLM como ferramenta de apoio ao estudo do Power BI, utilizando exclusivamente documentação oficial da Microsoft como base de conhecimento.

O objetivo foi avaliar a capacidade do NotebookLM em organizar, correlacionar e sintetizar grandes volumes de documentação técnica, produzindo resumos, comparações, fluxos de trabalho e materiais de apoio ao estudo.

---

# Objetivos

- Construir um caderno temático sobre Power BI utilizando o NotebookLM.
- Utilizar apenas documentação oficial da Microsoft como fonte de pesquisa.
- Aplicar técnicas de engenharia de prompts para explorar diferentes formas de consulta.
- Avaliar a qualidade das respostas produzidas pela IA.
- Consolidar um material de estudo organizado para futuras consultas.

---

# Curadoria de Fontes

Foram utilizadas as seguintes documentações oficiais da Microsoft Learn:

1. Documentação Oficial do Power BI
2. Documentação Oficial do Power Query
3. Documentação Oficial do Microsoft Fabric
4. Documentação Oficial da linguagem DAX
5. Documentação Oficial de Relatórios e Dashboards do Power BI

Todas as fontes foram adicionadas ao NotebookLM para criação de uma única base de conhecimento integrada.

# Miniguia de Estudo

## Resumo

O Power BI é uma plataforma de Business Intelligence composta por diferentes componentes que trabalham de forma integrada.

O fluxo de desenvolvimento normalmente segue esta sequência:

1. Conectar aos dados.
2. Transformar dados utilizando o Power Query.
3. Construir o Modelo Semântico.
4. Criar medidas utilizando DAX.
5. Desenvolver relatórios.
6. Publicar no Serviço do Power BI.
7. Compartilhar dashboards e aplicativos.

---

## Glossário

| Termo | Descrição |
|--------|-----------|
| Power Query | Ferramenta de preparação e transformação de dados. |
| Modelo Semântico | Camada responsável pela organização dos dados e relacionamentos. |
| DAX | Linguagem utilizada para criação de medidas e cálculos analíticos. |
| Power BI Desktop | Ambiente de desenvolvimento dos relatórios. |
| Power BI Service | Plataforma em nuvem para publicação e compartilhamento. |
| Dashboard | Painel consolidado com indicadores estratégicos. |
| Workspace | Espaço colaborativo para desenvolvimento e publicação. |
| Microsoft Fabric | Plataforma unificada de dados e análise da Microsoft. |
| OneLake | Camada central de armazenamento de dados do Microsoft Fabric. |
| RLS | Segurança em Nível de Linha utilizada para controlar acesso aos dados. |
